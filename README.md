# **AI-based Fruits and Vegetables Recognition System**  

An **AI-powered image classification system** that identifies **fruits and vegetables** using **deep learning and computer vision**.  

---

## **Overview**  
This project leverages **Convolutional Neural Networks (CNNs)** to classify images of various **fruits and vegetables**. It is trained on a dataset with multiple categories and can predict food names from images.  

### **Key Features**  
✔️ **Deep Learning-Based Classification**  
✔️ **Dataset Augmentation for Accuracy Improvement**  
✔️ **Real-Time Prediction Using Webcam**  
✔️ **Optimized Model for Mobile & Web Deployment**  

---

## **Dataset**  
- **Source:** [Kaggle - Fruit and Vegetable Image Recognition Dataset](https://www.kaggle.com/datasets/kritikseth/fruit-and-vegetable-image-recognition)  
- **Categories:** Apples, Bananas, Carrots, Tomatoes, Onions, and more.

## **Installation & Setup**  

### **1️⃣ Clone the Repository**  
```bash
git clone https://github.com/your-username/AI-based-Fruits-and-Vegetables-Recognition-System.git
cd AI-based-Fruits-and-Vegetables-Recognition-System
```

### **2️⃣ Install Dependencies**  
```bash
pip install tensorflow keras numpy pandas matplotlib opencv-python
```

### **3️⃣ Train the Model**  
```bash
python train.py
```

### **4️⃣ Run the Web App**  
```bash
python app.py
```
- Open `http://127.0.0.1:5000/` in a browser and upload an image for prediction.  

---

## **Model Architecture**  
The model is built using **CNN (Convolutional Neural Networks)** with:  
- **Convolutional Layers** for feature extraction.  
- **MaxPooling Layers** to reduce spatial dimensions.  
- **Dense Layers with Softmax Activation** for classification.  

---

## **Results & Performance**  
✔️ **Achieved 95%+ accuracy** on test data.  
✔️ **Real-time Image Classification** with webcam support.  
✔️ **Optimized for Faster Inference** using MobileNetV2.
